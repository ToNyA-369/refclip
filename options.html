RefClip 設定

儲存位置與圖片標記

網頁截圖

目前快捷鍵：讀取中…

在 Chrome 快捷鍵設定找到 RefClip，修改「框選網頁截圖並加上標籤」。按快捷鍵後拖曳框選，或選整個可見區域，再填標籤儲存；Esc 取消。

標籤類別與命名

依下列順序組成檔名。多標籤以空白分隔，每個標籤各套用前後綴；單段文字保留空白。前後綴可留空。

前後綴原樣使用，各最多 12 字元。系統不允許的符號會提示修改，不會自動轉成全形。

按下方「儲存設定」後，新開的收圖表單即會套用。

自訂本機資料夾

尚未讀取

選擇完成會立即記住路徑；請再按「儲存設定」啟用本機模式。每次收圖不會詢問檔名或位置。

首次安裝／連線排錯
  1. Windows 開啟 native\install.cmd；macOS 執行 native/macos/install.command（需 Python 3.9+）。兩者均不需管理員權限。
  2. 安裝程式會嘗試找到此專案的 Chrome ID；若要求輸入，複製下方 ID。
  3. 安裝完成後按「重新檢查連線與位置」，再選擇資料夾。

移動未封裝專案後 ID 可能改變，請重跑安裝。更新與移除步驟詳見 README。

僅在 Chrome 下載模式使用，例如 DrawingReferences/Pose。

本機模式不列入 Chrome 下載紀錄；寫入失敗不會切換目的地。
